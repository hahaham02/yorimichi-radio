# よりみちラジオ

歩いている場所の近くにある歴史やスポットを探し、スマートフォンの音声合成でラジオのように読み上げる、キー登録不要の静的Webアプリです。

## 起動方法

位置情報を使うため、HTTPSで公開するか、ローカル開発サーバーから開いてください（`localhost` は利用できます）。`index.html` を直接 `file://` で開くと、位置情報や外部APIがブラウザーに拒否される場合があります。

静的ファイルをHTTPS対応のホスティングに配置すれば公開できます。ビルドやパッケージのインストールは不要です。

## 使い方

1. HTTPSのページをスマートフォンで開き、「散歩をはじめる」を押します。
2. ブラウザーの位置情報利用を許可します。
3. 半径500mのWikipedia記事と地図上の歴史スポットを検索し、近い順に音声で案内します。
4. 「前へ／次へ」ボタンやスポット一覧から物語を選べます。音声を一時停止・再開したり、散歩を終了したりできます。歩いて120m以上移動するか45秒経つと周辺情報を更新します。

開始ボタンを押すと、音声再生を開始できることを確認する短い案内が流れます。解説は記事の冒頭を最大3文にまとめ、散歩番組風の導入と徒歩距離を添えて、少しゆっくり読み上げます。端末が自然音声・拡張音声を提供している場合は優先しますが、声質は端末・ブラウザーの音声設定により異なります。読み上げ音声が利用できない場合は理由を表示します。音声再生中は対応ブラウザーの画面スリープ抑止機能を使いますが、すべてのスマートフォン／ブラウザーでバックグラウンド再生が保証されるわけではありません。初回の位置情報許可と音声の開始には画面上の操作が必要です。イヤホンを使い、周囲の安全に注意してお楽しみください。

## スマートフォンで試す

`yorimichi-radio.zip` を展開し、4つのファイルをHTTPS対応の静的ホスティングに配置してください。発行されたHTTPSのURLをスマートフォンで開き、位置情報を許可すると、その端末の現在地を取得します。`file://` で開いた場合や、HTTPSでないスマートフォン向けURLでは、ブラウザーが位置情報を許可しないことがあります。

## 利用する無料APIとデータ

- [Wikipedia API](https://www.mediawiki.org/wiki/API:Main_page): 近くの記事と冒頭の解説文（日本語・英語）
- [OpenStreetMap Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API): 史跡、記念碑、博物館、地名などのスポット
- ブラウザー標準のGeolocation APIとWeb Speech API: 現在地の取得と音声読み上げ

APIキーや位置情報のサーバー保存はありません。Wikipediaの解説文は各記事へのリンクとともに表示します。地図情報のみに登録されたスポットについては、その名称と地図上の分類を案内し、確認できない由来や出来事は補いません。位置情報の利用には端末とブラウザーの許可が必要です。
